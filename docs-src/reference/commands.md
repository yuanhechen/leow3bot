# 命令

斜杠命令在输入框直接键入，`Tab` 补全：

| 命令 | 作用 |
|---|---|
| `/help` | 列出全部命令 |
| `/model [名称]` | 交互式模型选择器；带名称直接切换并持久化 |
| `/context` | 开关底部上下文占用条 |
| `/perf` | 开关底部性能指标 |
| `/verbose` | 展开 / 折叠思考过程 |
| `/compact` | 压缩上下文（图片摘要 + 旧工具结果截断） |
| `/clear` | 清空当前对话 |
| `/save` | 保存当前会话 |
| `/load` | 加载历史会话 |
| `/sessions` | 历史会话列表 |
| `/tools` | 查看已加载工具 |
| `/skills` | 查看与开关已加载的 skill |
| `/history` | 当前会话历史消息 |
| `/status` | 当前状态（模型 / 端点 / 上下文 / 工作目录） |
| `/q` | 退出 |
