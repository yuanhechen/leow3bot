# 快速上手

## 三行跑起来

```bash
npm install -g @leow3lab/leow3bot
leow3bot        # 首次启动进入四步引导，答完即用
```

首次启动会引导你完成端点、Key、模型选择——全程无需编辑任何配置文件，详见[首次启动与配置](/guide/onboarding)。

## 第一个任务

启动后直接用自然语言描述任务：

```
❯ 帮我看看当前目录有哪些源码文件，梳理下结构
```

leow3bot 会自主浏览目录、阅读文件并给出结构总结。更多场景见[日常使用](/guide/usage)。

## 中断与退出

- 生成过程中按 `Esc` 中断（保留已生成部分）
- 输入 `/q` 或按 `q` 退出
